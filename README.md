# Taverna Antica — Demo Site

Sito demo per Taverna Antica, ristorante di pesce · Praia a Mare (CS), Calabria.

## Stack

- HTML + Tailwind CSS Play CDN (v3)
- Google Fonts: Fraunces · DM Sans · EB Garamond
- Nessuna dipendenza npm · deploy diretto su GitHub Pages

## Deployment

```bash
# GitHub Pages: push su main, Pages da root /
git add .
git commit -m "feat: taverna antica demo site"
git push
```

## ⚠️ Note di sicurezza

**Tailwind Play CDN non supporta SRI** (`integrity=` hash) perché genera CSS dinamicamente.
Accettabile per demo/staging. In produzione: compilare Tailwind localmente e servire file statico.
